Zambezi Rapids Adventures

WDD 131 Website Planning Document

Site Name

Zambezi Rapids Adventures

The name was chosen because the website focuses on rafting adventures along the Zambezi River. "Rapids Adventures" communicates the exciting outdoor experience that visitors can learn about through the website.

Site Purpose

Zambezi Rapids Adventures will provide information for people interested in river rafting and outdoor adventures. The website will provide information about rafting trips, safety, preparation, prices, and what visitors should expect before going on a rafting adventure.

The website will also help visitors understand the different rafting options and decide which experience is suitable for them.

Scenarios

Scenario 1

"What should I bring with me when I go rafting for the first time?"

Scenario 2

"How much does a rafting trip cost and what is included in the price?"

Scenario 3

"Is rafting suitable for someone who has never rafted before?"

Color Schema

River Blue - #006994

Used for headings, navigation, buttons, and important accents. Blue represents the Zambezi River.

Adventure Green - #2E7D32

Used for secondary headings, highlights, and adventure-related sections. Green represents the natural environment around the river.

River Sand - #F4E7D3

Used as a light background color for sections and cards. It provides contrast with the darker river colors.

Typography

Heading Font: Trebuchet MS

Trebuchet MS will be used for the main headings, section headings, navigation, and important labels. It provides a clear and energetic appearance suitable for an outdoor adventure website.

Body Font: Arial

Arial will be used for paragraphs and general information because it is simple, readable, and easy to view on different screen sizes.
